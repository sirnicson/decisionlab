# V2.3.2 — DecisionLab Brand Lock-up Refinement

Status: **AUTHORITATIVE V2.3.2 AMENDMENT**

This amendment changes only the sidebar DECISIONLAB lock-up. All V2.3.1 workspace architecture, task navigation, Sea Wolf layout, result integration, game mechanics, scoring, persistence and Learning/Simulation behaviour remain unchanged.

## 1. Sidebar lock-up

The sidebar brand is a single horizontal lock-up:

`[D mark] DECISIONLAB`

Do **not** render `Client Advisory Workspace` beneath this lock-up.

`Client Advisory Workspace` remains the global workspace label elsewhere in the application, including the persistent topbar, and continues to replace `Independent Preparation Workspace` globally.

## 2. D mark geometry

- rotate the lime mark **10 degrees clockwise**;
- keep the `D` itself upright by counter-rotating it inside the mark;
- size the mark as a compact companion to the wordmark, not a dominant badge;
- the mark should extend only slightly above and below the visual height of `DECISIONLAB`;
- reference implementation: **22px mark** beside an **18px wordmark** at the current desktop sidebar scale.

## 3. D typography and centring

- centre the glyph both horizontally and vertically inside the mark;
- use the system UI / Apple-oriented sans-serif stack: `-apple-system, BlinkMacSystemFont, SF Pro Display, Helvetica Neue, Arial, sans-serif`;
- use a restrained semibold/bold treatment rather than the earlier heavy display weight;
- preserve strong legibility at the compact mark size.

## 4. Wordmark

- `DECISION` remains stronger and white;
- `LAB` remains lighter and lime;
- no gap is inserted between `DECISION` and `LAB`;
- the mark-to-wordmark gap should remain compact and intentional.

## 5. Acceptance criteria

V2.3.2 passes when:
1. the mark tilts 10° to the right;
2. the `D` is visually centred and upright;
3. the mark is no longer materially larger than the wordmark;
4. the sidebar subtitle is absent;
5. `Client Advisory Workspace` remains visible in the topbar/workspace context;
6. no task mechanics or application behaviour changes.
