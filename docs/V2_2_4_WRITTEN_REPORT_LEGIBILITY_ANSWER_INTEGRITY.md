# V2.2.4 — Written Report Legibility & Answer Integrity

Implemented across all three Red Rock studies.

## UI
- Compact Written Report inputs (118 px × 32 px desktop target).
- Baseline alignment and reduced horizontal margins.
- Neutral `—` placeholder; unit appears once beside the field.
- Graph Selection keeps its wider grid-specific input treatment.

## Narrative audit
- Salvanova, Caldera and Norvale report prose was rewritten around the same existing fields.
- Non-field copy no longer supplies report-field benchmark numbers.
- Caldera no longer states that the complete threshold set is reached at the end of the programme outside the target-year field.
- Norvale no longer states that delivery is feasible within the five-year horizon outside the capacity-required field.
- Quantitative fields, answers, units, tolerances and scoring are unchanged.
