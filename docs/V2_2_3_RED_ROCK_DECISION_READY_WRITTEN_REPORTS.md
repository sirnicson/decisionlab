# V2.2.3 — Red Rock Decision-Ready Written Reports

## Change
All three Red Rock Written Reports now use fuller consultancy-adjacent decision narratives while preserving the same scored data fields and benchmark values.

## Locked narrative grammar
**Situation / decision context → evidence or baseline/feasibility → programme/intervention implication → recommendation and management implication**

## Study application
- **Salvanova Forest:** ecosystem imbalance → no-intervention trajectory → wolf-reintroduction effect → support recommendation with monitoring.
- **Caldera Marsh:** water-quality problem → five-year indicator movement → threshold/fish/visitor implications → programme-backing recommendation.
- **Norvale Highlands:** restoration challenge → scale/cost/capacity feasibility → forest-cover/carbon outcomes → proceed recommendation with delivery-capacity guardrail.

## Guardrail
No report field IDs, answer keys, tolerances, units, scoring weights, Investigation data, Analysis questions, Graph Selection logic or Visual Report cases were changed.
