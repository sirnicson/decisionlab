# V2.2.5 — Result Feedback and Client Concern

## Locked changes

- Item-level result status is **Correct** (green) or **Needs review** (red).
- Raw internal reasoning tags such as `FORMULA_SETUP`, `WRONG_DENOMINATOR` and `READ_OBJECTIVE` are not rendered to learners.
- The Task 1 Results page does not reproduce the learner's submitted graph. Graph review is textual: chart-choice suitability plus entered-data accuracy.
- `Primary constraint` is replaced by **Primary Concern**. The concern is written from a client perspective and synthesises the most consequential weighted weakness, with explicit attention to whether analysis is translating into a defensible report.
- Red Rock assessment weights are: Analysis 40%, Written Report 20%, Graph Selection 10%, Visual Report Cases 20%, Evidence Selection 10% = **100%**.
- Time used remains visible for practice context but contributes **0%** to the Task 1 score.
- Every assessment component has predefined threshold feedback: 85–100 client-ready; 70–84 directionally sound; 51–69 material gap; 0–50 significant concern, with component-specific client wording.
