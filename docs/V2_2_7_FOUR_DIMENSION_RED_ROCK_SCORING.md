# V2.2.7 — Four-dimension Red Rock scoring

Task 1 Red Rock now uses exactly four scored dimensions:

- Analysis — 50%
- Written Report — 20%
- Graph Selection — 10%

Primary Concern synthesises the four scored dimensions and includes a compact four-row performance snapshot inside the same client-review card.
