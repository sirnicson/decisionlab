# Solve It Readiness Lab — V2.2.3

**DecisionLab** is an independent educational practice application for structured problem solving under time pressure. V2.2.8 is the current integrated build governed by the Fairhaven Environmental Trust consulting narrative, the sealed Red Rock workflow, the validated Sea Wolf workflow, and a research-informed environmental data deck.

> This is not an official McKinsey product. It does not reproduce proprietary scoring, percentiles, hiring decisions, logos, artwork or protected assessment content.

> **V1.2.2 correction:** Characteristic selection now materially generates the six-card Initial Prospect Pool from a fixed 12-card profiling candidate universe. This is a correction within V1.2, not a deferred V1.3 feature.

## Engagement

The learner joins an advisory team supporting the fictional **Fairhaven Environmental Trust — Environmental Recovery Programme** across two workstreams.

- **Workstream 01 — Red Rock Studies** is sponsored by **Dr. Elena Cross, Director of Land & Ecosystem Recovery**. The learner investigates evidence, performs quantitative analysis and prepares a decision-ready report.
- **Workstream 02 — Sea Wolf Studies** is sponsored by **Dr. Paula Reyes, Lead Marine Biologist**. The learner profiles site needs, routes microbes, builds prospect pools and submits three-microbe treatments across three connected sites.

The consulting frame is deliberately light. Reasoning support is embedded in client briefs, working prompts, decision feedback and post-session review rather than shown as a persistent methodology framework.

## Modes

### Learning Mode

Launch an individual Red Rock or Sea Wolf study. An optional timer is available. Contextual guidance is delivered in the client/sponsor voice. Submitted routing decisions may receive concise client feedback; Prospect Selection remains editable until confirmation and is assessed in the later client/result review.

### Simulation Mode

Select exactly one Red Rock study and one Sea Wolf study. The combined allowance is **65 minutes**: Red Rock 35 minutes + Sea Wolf 30 minutes, excluding instructions. Simulation Mode gives no live correctness, allocation classification or treatment-quality feedback.

## Task 2 — Sea Wolf

V1.2 includes three fixed studies, each with three connected sites:

- Cinder Bay
- Tidal Reach
- Azure Shelf

The study flow is:

`Introduction → Site 1 → Site 2 → Site 3 → Task 2 Results`

The learner-facing process is:

`Characteristics → Categorisation → Selection → Treatment`

### Two separate streams

**Routing stream:** a separate 10-microbe deck is categorised to Current Site, Next Site or Return. Microbes sent forward are reassessed when the next site's complete information becomes available.

**Treatment-building stream:** each site contains a fixed 12-microbe profiling candidate universe. Selecting any two characteristics deterministically derives the six-microbe Initial Prospect Pool from that universe. Four sequential one-of-three choices then grow the pool from 6 to 10, after which the learner selects exactly 3 microbes for the site treatment.

Categorisation never creates the Initial Prospect Pool.

### Characteristic-profiled Initial Prospect Pool

V1.2 no longer uses one static six-card pool per site. The learner selects two of seven characteristics (3 attributes + 4 traits), creating 21 possible pairs. The engine ranks a fixed 12-card treatment-profiling universe and deterministically returns six cards. The demonstrated A + Desired Trait choice reproduces the validated reference six, while alternative pairs materially change the pool. Prospect-selection feedback is computed against the learner's actual derived pool rather than a static answer key.

### Routing rule

A microbe qualifies for Current Site when at least two of four positive criteria match — Permeability, Mobility, Energy and Desired Trait — **and** the Undesired Trait is absent. If it does not qualify, the learner uses the limited Next Site Insight where available; otherwise the microbe is returned.

### Trait vocabulary

Every V1.2 Sea Wolf microbe has exactly one of four traits:

- Heat Resistant
- Aerobic
- Phosphorus Removal
- Light Sensitive

There is no Neutral trait in V1.2.

### Treatment effectiveness

The final trio is scored on five criteria worth 20 percentage points each:

1. average Permeability is in range;
2. average Mobility is in range;
3. average Energy is in range;
4. no selected microbe carries the Undesired Trait;
5. at least one selected microbe carries the Desired Trait.

Multiple different trios may achieve the same optimum. Azure Shelf Site 3 is intentionally constrained to a maximum feasible effectiveness of 80%; the practice score normalises performance against that feasible maximum.

## Scientific-plausibility rule

The cases use a **research-informed data deck**. Primary geographical, ecological, environmental-microbiology and bioremediation research informs the direction of relationships, plausible sensitivities, traits and trade-offs. Deterministic learner-facing values are synthetic training data unless explicitly stated otherwise.

Sea Wolf `Permeability`, `Mobility` and `Energy` are abstract **1–10 game indices**, not laboratory measurements. The game is designed for coherent environmental decision-making, not scientific simulation fidelity.

## Run locally

Requires Node.js 20+.

```bash
npm install
npm run dev
```

Then open the local Vite URL displayed in the terminal.

## Validation and build

```bash
npm run validate:data
npm test
npm run build
```

Install Chromium once and run the browser-level smoke test with:

```bash
npx playwright install chromium
npm run test:e2e
```

Or run the full check:

```bash
npm run check
```

Sea Wolf validation checks, among other invariants:

- exactly 10 routing microbes per site;
- exactly 12 fixed profiling candidates per site, with all 21 two-characteristic combinations validated to derive exactly 6 unique Initial Prospect Pool microbes;
- exactly four prospect rounds containing 3 candidates each;
- all **81** prospect-selection paths for every characteristic-derived pool — **1,701 paths per site** — and a 10-card final pool on every path;
- 1–10 attribute indices and the locked four-trait vocabulary;
- every 3-of-10 treatment combination on each reachable final pool;
- declared maximum-feasible treatment effectiveness;
- multiple maximum-scoring trios where applicable;
- Azure Shelf Site 3 maximum effectiveness = 80%.
